# Programando um semáforo com Arduino UNO

Projeto desenvolvido para estudo de programação de microcontroladores, utilizando um Arduino Uno para controlar um sistema de semáforo com LEDs e botões.

O projeto tem como objetivo aplicar, na prática, conceitos de programação em C/C++, lógica digital, manipulação de bits e controle de entradas e saídas digitais.


## Conhecimentos

 - Conexões físicas no Arduino Uno e no protoboard
 - Desenvolvimento em C/C++
 - Uso da ferramenta arduino-cli


## Autores

- Natanael Rodrigues

## Objetivos
- Controlar LEDs por meio do Arduino Uno
- Utilizar botões como entradas digitais
- Desenvolver lógica de acionamento e desligamento
- Praticar programação para microcontroladores
- Integrar software e hardware em um projeto funcional.

## Como executar

1. Monte o circuito na protoboard conforme o esquema do projeto.
2. Conecte o Arduino Uno ao computador utilizando o cabo USB.
3. Abra o código na Arduino IDE.
4. Selecione:
   - Placa: Arduino Uno
   - Porta: porta correspondente ao Arduino
5. Compile o código.
6. Faça o upload para o Arduino.
7. Teste os botões e observe o comportamento dos LEDs.

## Funcionamento

O Arduino monitora as entradas provenientes dos botões e, de acordo com o estado detectado, controla as saídas conectadas aos LEDs.

A lógica do programa é responsável por determinar quais LEDs devem permanecer ligados ou desligados em cada situação.

## Objetivo acadêmico

Este projeto foi desenvolvido como parte da formação prática em programação de microcontroladores e sistemas embarcados, buscando aproximar conceitos de programação de baixo nível da interação real com hardware.
